# Who Wants to Be a Millionaire — JavaFX Edition

A desktop version of the classic quiz show *Who Wants to Be a Millionaire*, built in Java with JavaFX. A project by me and a friend.

## About

Play your way up the prize ladder by answering multiple-choice questions correctly. Get one wrong and you walk away with whatever safety-net amount you've banked. Get them all right and you win the top prize.

## Features

- Classic 15-question money ladder
- Multiple-choice question format
- Clean JavaFX UI styled with CSS
- Packaged as a runnable jar

## Tech Stack

- **Java** — core game logic
- **JavaFX** — UI framework
- **CSS** — styling
- **Maven** — build and dependency management (with Maven wrapper included)

## Running It

Clone the repo and either run the prebuilt jar:

```bash
java -jar app.jar
```

Or build from source with the included Maven wrapper:

```bash
./mvnw clean javafx:run
```
